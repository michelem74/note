Hi, I looked around and saw this has come up a couple of times and when I first started using Zettlr it was something I missed after using Joplin and Obsidian both which have good web clippers. I was using one of the Obsidian web clippers for Zettlr for a while (using the same file set) however then I found this below.

[https://chrome.google.com/webstore/detail/markdownload-markdown-web/pcmpcfapbekmbjjkdalcgopdkipoggdi?hl=en-GB](https://github.com/Zettlr/Zettlr/discussions/4771url)

It gives you so much control over how you clip and does a really great job. Available for Chrome, Edge etc and Firefox. Clip then save the MD file to your Zettlr directory and you are done. It's pretty cool actually. So, this is the perfect Zettlr web clipper for me.

Apologies if this is a double post but just wanted to share.

Github page is here [https://github.com/deathau/markdownload](https://github.com/Zettlr/Zettlr/discussions/4771url)
